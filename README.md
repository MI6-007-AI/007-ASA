# 007 ASA — ARK Survival Ascended Automation Suite

007 ASA is a free automation suite for ARK Survival Ascended. Auto-reconnect, AFK guard, auto-clicker, resource calculators, overlays and more. Built for serious ARK players.

## Features
- Auto-Reconnect — automatically rejoins your server if you disconnect
- AFK Guard — keeps you active so you don't get kicked
- LogBot — monitors your game log for events
- AutoSim — automates repetitive actions
- Dino Raising Calculator
- Resource Calculator
- Timers
- To-Do List
- Music Player
- Overlay & Crosshair
- Auto-Updater — always stay on the latest version

## How to Update
Open 007 ASA → Settings → click **Check for Updates**
